# 粘贴管理器

常驻后台的 Windows 剪贴板历史工具。**全部数据留在本机**，不联网、不上传。

- 全局热键 `Ctrl+Shift+V` 唤出搜索浮层，选中回车即**自动替你粘贴**到刚才那个窗口
- 记录文本、图片、复制的文件；带「排除监控」标志的内容（密码管理器）自动跳过
- 收藏/置顶永久保留，其余最多 500 条（图片另有 100 张上限）
- 自动识别类型（链接 / 颜色 / 代码 / 路径 / 图片 / 文件），标签由你自己打
- 纯离线 SQLite 存储，可导出可导入

## 运行

双击 `start.cmd`。会发生三件事：

1. 弹出一个控制台窗口（**别关，关掉就等于退出程序**）
2. 面板自动亮一次 —— 手动启动会弹面板，开机自启拉起时不会（那种情况不该抢焦点）
3. 控制台里写明**本次实际生效的热键**：`已就绪，按 Control+Shift+V 唤出面板`

之后面板收起来就常驻托盘，按热键或点托盘图标都能唤出。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl+Shift+V` | 唤出 / 收起浮层（全局，可在设置里改） |
| `↑` `↓` `PgUp/PgDn` | 选择 |
| `Enter` | 自动粘贴到唤出前的那个窗口 |
| `Esc` | 有搜索词先清空；设置页里退出设置；否则收起面板 |
| `Tab` / `Shift+Tab` | 切换类型筛选 |
| `Ctrl+P` | 收藏 / 取消收藏 |
| `Ctrl+T` | 给选中条目打标签 |
| `Ctrl+,` | 打开设置（也可以点搜索框右边的 ⚙） |
| `Ctrl+Del` | 删除该条 |
| 右键条目 | 只用剪贴板复制、设置标签、收藏、删除 |
| 鼠标点击条目 | 直接粘贴 |

每次唤出浮层都会**回到干净状态**（清空搜索词、筛选回到「全部」），避免上次的筛选
把列表过滤成空、被误当成历史丢了。

## 安装 / 直接使用

```bash
npm install
npm run pack
```

产物（`dist\`）：

| 文件 | 说明 |
| --- | --- |
| `paste-manager-0.1.0-setup.exe` | **推荐**。安装到本机（可改安装路径），有开始菜单/桌面快捷方式，卸载时会清掉开机自启项 |
| `paste-manager-0.1.0-portable.exe` | 免安装单文件，双击即用。缺点：每次启动要先自解压到临时目录，启动慢几秒 |
| `win-unpacked\` | 解压好的绿色目录版，启动最快，可直接整个文件夹拷走 |

三个版本共用同一份数据目录（`%APPDATA%\粘贴管理器\`），互相切换不会丢历史。

> 开机自启建议用**安装版**：免安装单文件版如果被移动或删掉，自启项就失效了。

## 设置面板里能改什么

- **唤出热键**：点输入框后直接按组合键即可录制。会检测是否被别的软件占用；
  抢不到时**本次运行**先用回退键（`Control+Alt+V`）并把原因显示在底栏，但**你的选择会原样保留**，
  下次启动会重新尝试你设的那个键 —— 偶发的一次冲突不会永久改掉你的设置。
  想确认某个键当前是否空闲，可以跑 `test\manual\hotkey-probe.ps1`。
- **历史条数 / 图片张数 / 单张图片大小上限**：改完立刻按新上限清理一次。
- **自动粘贴前等待**：粘不进去时调大一点，给原窗口回到前台留时间。
- **文件回填方式**：文件列表 / 纯文本路径。
- **开机自启**：开机后在托盘静默启动（不弹面板、不抢焦点）。
- **导出 / 导入 JSON**、**打开数据目录**。

**热键和开机自启在托盘图标右键菜单里也能直接改**，不用先想起 `Ctrl+,`：

```
唤出面板
─────────────────
设置热键…（当前 Control+Shift+V）
☑ 开机自动启动
─────────────────
暂停记录剪贴板
历史：123 条（收藏 4 · 图片 7 · 812 KB）
─────────────────
打开数据目录
退出
```

### 关于开机自启

- **打包版首次运行默认开启**（用户要的就是这个）。你手动关一次就会永久记住，不会被再次打开。
- 自启项指向"你实际双击的那个 exe"：
  - 安装版 → 安装目录里的 exe
  - 免安装单文件版 → 你双击的那个 portable exe（`PORTABLE_EXECUTABLE_FILE`），
    而不是它每次运行时解压出来的临时路径 —— 否则下次开机自启项就失效了
  - 开发模式 → `electron.exe` + 项目路径
- **卸载时会自动删除自启项**（见 `build/installer.nsh`），不会留下一条指向已删除程序的启动项。
- 开机自启拉起时**不弹面板**（那种情况不该抢焦点）；手动双击启动会弹一次。

## 数据在哪

`%APPDATA%\粘贴管理器\`

- `paste.db` — SQLite（文本、类型、收藏、使用次数）
- `blobs/` — 图片原图
- `paste-helper.ps1` — 仅在原生助手缺失时才用的 PowerShell 回退脚本

托盘右键 → 「打开数据目录」可直接跳过去。想搬到别处（比如 U 盘），设环境变量
`PASTE_MANAGER_DATA=路径` 即可（该变量也会把 Chromium 自己的缓存一起挪走）。

## 内存占用

常驻后台的工具，内存是持续成本。实测（同一份 503 条历史 / 20 张截图的数据）：

| 状态 | 优化前 | 优化后 |
| --- | --- | --- |
| 面板打开 | 530 MB 工作集 / 356 MB 私有 | 418 MB / 118 MB |
| 面板收起（稳态） | 约 400 MB / 294 MB | **241 MB / 86 MB** |

四处优化：

1. **空闲销毁窗口**（`main.js` 的 `OVERLAY_IDLE_DESTROY_MS`，默认 2 分钟）
   面板收起一段时间后把整个 BrowserWindow 销毁，渲染进程直接回收（这是最大的一块）。
   代价：闲置后第一次唤出要多 ~220ms 重建窗口；连续使用（2 分钟内）仍是 60ms 热启动。
2. **关掉硬件加速**（`app.disableHardwareAcceleration()`）
   这个界面没有视频/WebGL，不需要独立 GPU 进程。实测 GPU 进程私有内存 97 MB → 17 MB。
3. **图片懒加载 + 只渲染一屏范围**（`RENDER_LIMIT = 60`，`loading="lazy"`）
   一张截图解码后可能十几 MB，原来列表把 300 行（含全部图片）一次塞进 DOM。
   现在只渲染选中项附近 60 行，图片滚到可见位置才解码；面板收起时还会清空列表 DOM。
4. **原生助手替代 PowerShell 助手**（`resources/paste-helper.exe`，5.5 KB）
   原来常驻一个 PowerShell 进程做「夺前台权 + Ctrl+V」，占 54~77 MB；换成编译好的小
   .NET 程序后只占 **14 MB**，启动也从 ~400ms 降到几十毫秒。
   源码在 `resources/paste-helper.cs`，用系统自带的 csc 编译（无需 SDK）；
   找不到这个 exe 时会自动退回 PowerShell 版本。

想复核数字：先启动应用，再跑
`powershell -ExecutionPolicy Bypass -File test\manual\mem-report.ps1`
（逐个进程列出工作集/私有内存并求和）。

### 第二轮：泄漏 / 常驻对象 / 资源未释放专项

第一轮砍掉的是"大头常驻"；这一轮清理的是**随时间累积或随内容变大**的部分。
共 8 处，全部不改变业务行为（`node test/store.test.js` 15 项全过）：

| # | 位置 | 问题 | 修法 |
| --- | --- | --- | --- |
| 1 | `store.js` | 热路径 SQL 每次调用都 `db.prepare()`，原生语句句柄在两次 GC 之间持续累积（每次抓取提交都走 `enforceLimits`/`_nextStamp`） | 固定 SQL 构造期一次 prepare 长期复用；`list()` 动态 SQL 按形态缓存（键空间有界）；导入不再逐行 prepare `last_insert_rowid` |
| 2 | `store.js` | `list()` 每次把**全库** `item_tags` 连接表读出来建 Map，随历史无界增长 | 只按当前页条目 id 查标签（语句按页长缓存） |
| 3 | `capture.js` | 上一段剪贴板文本**整段常驻**主进程：复制大文档后一直扣着数 MB 字符串（UTF-16 再翻倍） | 只存 SHA1 指纹，判重语义与原字符串比对一致 |
| 4 | `capture.js` | 超限大图仍被**整块读入内存**、算完哈希才丢弃：30MB 截图挂在剪贴板上时约每 5.6s 重复分配一次 | `blob.size` 预判，超限内容零读取；警告与降频节奏保持不变 |
| 5 | `renderer/app.js` | 面板隐藏期间每条新剪贴板都会把 300 条数据 + DOM 重新塞回**隐藏窗口**，把 `onHidden` 的清理反复撤销 | 按 `document.visibilityState` 守卫；唤出时 `onShown` 本来就全量刷新 |
| 6 | `renderer/app.js` | 面板打开期间 `state.items` 扣着最多 300 条**整段原文** | 数据落地即裁剪为「折叠后 600 字符 + 是否含换行」，渲染结果逐字符一致 |
| 7 | `main.js` / `tray.js` | 退出时托盘从不销毁（通知区幽灵图标 + 图标位图/菜单句柄不释放）、空闲销毁与焦点夺回定时器不清理 | `will-quit` 里销毁托盘（先摘事件回调）、清掉两个定时器 |
| 8 | `main.js` | 旧窗口迟到的 `closed` 事件会把**刚重建的新窗口**引用置空：活着的渲染进程失去句柄，再也无法隐藏/销毁（窗口泄漏）；首帧就绪的 2 秒兜底定时器用完不清 | `closed` 回调按窗口实例判等；就绪后立即 `clearTimeout` 兜底定时器 |

## 三个踩过的坑（改代码前先看这里）

**1. Electron 44 换了整套剪贴板 API。**
旧的 `availableFormats / readBuffer / writeBuffer / readImage / writeImage` 已全部删除，
取而代之的是 W3C 风格的异步接口：`clipboard.read()` → `ClipboardItem[]`（有 `types`
和 `getType()`）、`clipboard.readText() / writeText()` 返回 Promise。
原生格式走 `electron application/osclipboard;format="名字"`，
**文件列表走 `text/uri-list`**（Windows 上就是 `CF_HDROP`，粘到资源管理器里是真的复制文件）。
别照抄网上老代码。

**2. Windows 前台锁：这是"自动粘贴"最容易被卡死的地方。**
`hide()` 之后前台权不会自动回到你原来的窗口，此时模拟的 `Ctrl+V` 会打进一个不可见的
窗口直接丢掉；而普通进程直接 `SetForegroundWindow` 又会被系统拒绝。
现在的做法（`src/main/paste.js`）：常驻一个隐藏 PowerShell 助手，
唤出浮层**之前**记下前台窗口句柄，按下回车后由助手
`AttachThreadInput(挂到当前前台窗口的线程) → SetForegroundWindow(原窗口) → 再确认一次 → SendKeys ^v`。
注意必须挂到**当前前台窗口**的线程上，挂目标窗口自己的线程是没用的。
有些后台程序（实测是汽水音乐）会反复抢焦点，所以助手在按键前会再抢一次。

**3. 给 PowerShell 和 cmd 的脚本必须纯 ASCII。**
`powershell.exe`（5.1）按 ANSI/GBK 读 `.ps1`，`cmd.exe` 同样按 ANSI 读 `.cmd`；
一条中文注释的末字节会吞掉换行符，把下一行整行拖进注释里，或者把两条命令拼成一条。
症状分别是"类型找不到 / C# 编译失败"和"`'lectron_config_cache锛園electron' 不是内部或外部命令"。
所以 `start.cmd`、`paste.js` 里生成的助手脚本、`test/manual/*.ps1` 全部只写英文
（`paste.js` 里还有断言，检测到非 ASCII 直接拒绝写入）。
脚本里确实需要中文时（比如比较中文窗口标题），用码点拼：[char[]](0x7C98,...)。

**4. 会抢焦点的后台程序是常态，不是异常。**
实测这台机器上汽水音乐、测试工具、甚至运行测试的终端本身都会抢前台：
浮层刚弹出来焦点就被抢走，用户接着敲的回车会落到别的窗口里（面板看着是开着的）。
现在的对策：弹出后头 1 秒内每隔 120ms 检查一次，焦点被抢就夺回来；1 秒后不再争抢，
用户主动点别处照常自动收起。端到端测试里目标窗口也会自己夺回前台，否则测的是环境不是代码。

**5. 偶发的失败不能写进配置。**
热键注册偶尔会和别的程序撞上（实测发生过一次）。第一版把回退结果存回了数据库，
于是"一次偶发冲突"变成"用户的热键被永久改掉"。现在回退只作用于本次运行，
用户设的值原样保留，下次启动重新尝试。

## 验证

```bash
node test/store.test.js                              # 存储层 + 类型识别，15 项
npx electron . --dev                                 # 带 DevTools 启动

# 真机端到端：先双击 start.cmd 把应用跑起来，再执行
powershell -ExecutionPolicy Bypass -File test\manual\e2e-paste.ps1
```

端到端脚本会开一个受控的目标窗口，然后走完
「热键 → 浮层获焦 → 回车 → 写回剪贴板 → 交还前台权 → Ctrl+V 落字」，
默认两轮全过才算 PASS。脚本会先确认目标窗口真的拿到了前台：拿不到就报
`SKIP`（环境问题，不赖应用）而不是假 FAIL，退出码 0=通过 / 1=失败 / 2=全被跳过。

调试开关（环境变量）：

| 变量 | 作用 |
| --- | --- |
| `PASTE_MANAGER_DEBUG=1` | 把取样、前台窗口、助手交互过程打到终端 |
| `PASTE_MANAGER_KEEP_OPEN=1` | 浮层失焦也不收起，方便截图排错 |
| `PASTE_MANAGER_DATA=路径` | 数据目录换个地方 |

## 已知边界

- **按键送不进去的窗口**：以管理员身份运行的窗口、部分 UWP / 全屏独占游戏。
  此时内容已经在剪贴板里，手动按一次 `Ctrl+V` 即可。
- **`Ctrl+Shift+V` 与「粘贴为纯文本」冲突**：热键是全局独占的，注册后会占用浏览器/Word
  里原本的「无格式粘贴」。热键存在设置里（`hotkey`），设置面板还没做，暂时改数据库。
- 复制的文件回填成 `text/uri-list`；个别程序只认文本，可把 `filesAsText` 设为 true。
- 未做：富文本（HTML/RTF）保留、云同步、多设备、标签界面（存储层已就绪）。
